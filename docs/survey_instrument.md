# Survey instrument

The Qualtrics survey measured four reflective constructs using a 7-point agreement scale:

**1 = Strongly disagree**  
**2 = Disagree**  
**3 = Somewhat disagree**  
**4 = Neither agree nor disagree**  
**5 = Somewhat agree**  
**6 = Agree**  
**7 = Strongly agree**

## Eligibility

**Have you ever used a generative AI tool such as ChatGPT, Gemini, Microsoft Copilot, Claude, or a similar tool for an academic task?**

Respondents who answered **No** were not eligible for the main study measures.

## Perceived Ease of Use (PEOU)

Adapted from Davis (1989).

- **PEOU1:** Learning to use generative AI tools for academic tasks is easy for me.
- **PEOU2:** My interaction with generative AI tools for academic tasks is clear and understandable.
- **PEOU3:** It is easy for me to become skillful at using generative AI tools for academic tasks.
- **PEOU4:** Overall, I find generative AI tools easy to use for academic tasks.

## Perceived Usefulness (PU)

Adapted from Davis (1989).

- **PU1:** Using generative AI tools helps me complete academic tasks more quickly.
- **PU2:** Using generative AI tools improves my performance on academic tasks.
- **PU3:** Using generative AI tools increases my productivity in academic work.
- **PU4:** Overall, I find generative AI tools useful for completing academic tasks.

## Social Influence (SI)

Adapted from UTAUT2 (Venkatesh, Thong, & Xu, 2012).

- **SI1:** People who are important to me think that I should use generative AI tools for academic tasks.
- **SI2:** People who influence my academic behavior think that I should use generative AI tools for academic tasks.
- **SI3:** People whose opinions I value support my use of generative AI tools for academic tasks.

## Behavioral Intention (BI)

Adapted from TAM-related behavioral-intention measures, including Davis, Bagozzi, and Warshaw (1989).

- **BI1:** I intend to continue using generative AI tools for academic tasks in the future.
- **BI2:** I plan to use generative AI tools regularly for academic tasks.
- **BI3:** I expect to use generative AI tools for academic tasks whenever they are appropriate and useful.

## Attention check

> To show that you are reading the questions carefully, please select **Agree** below.

Responses that failed the attention check were removed during data screening.

## Background variables

- Age in years
- Academic level
- Prior GenAI experience
- Frequency of GenAI use
- Preferred GenAI tool

Age and prior GenAI experience were used as control variables in the structural model. Academic level, frequency, and preferred tool were used for descriptive reporting.
