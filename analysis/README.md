# Analysis

`pls_sem_analysis.R` documents the core PLS-SEM workflow used in this project.

The script expects the private cleaned dataset at:

```text
data/GenAI_FINAL_SmartPLS_Ready.csv
```

The public repository does not include that respondent-level file. SmartPLS was used as the primary source for the final measurement and structural estimates reported in the manuscript; R was also used for predictive assessment and result-table generation.
